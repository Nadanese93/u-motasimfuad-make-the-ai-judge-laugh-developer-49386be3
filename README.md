## Entry

> It's DNS. It was always DNS. The worst part is that this time it actually was.

The worn "it's always DNS" deflection, turned on its head: this time it actually was DNS — which makes it worse, not better.

## How it works

`main.py` (Python standard library only) writes the entry to `$MAKEFUN_OUTPUT_DIR/entry.txt` with no trailing newline.
